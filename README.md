# Document QA RAG

A document question answering system built with Django, LangChain, PostgreSQL, pgvector, and OpenRouter.

## Project Overview

This project provides a backend system for managing documents and answering user questions based on the content of those documents using Retrieval-Augmented Generation (RAG).

## Planned Features

- Document management with Django
- DOCX file support
- Full-text extraction and storage
- Document chunking
- Semantic search
- Vector embeddings
- PostgreSQL with pgvector
- Retrieval-Augmented Generation (RAG)
- LangChain integration
- OpenRouter LLM integration
- Question and answer history
- REST API
- Swagger / OpenAPI documentation
- Django Admin interface
- Docker support
- Automated tests

## Technology Stack
